# Agent Note: 知识来源溯源

Status: implemented

[English](2026-09-05-knowledge-source-provenance.md) | 中文

## Problem

有长度限制的导航预览不能证明回答全文或完成状态。工具名称和时间相近也不能证明其支持某项研究结论。把其中任何一种当成发现，会让失败执行看似成功，并用误导性摘要遮住可用文件。

## Decision

知识卡片以轮次起点、事件序号和 Chat 节点键标识已加载原文。只有已完成轮次中最后一条已收敛、没有工具调用的 Assistant 消息可以贡献回答摘录。共享 Markdown 语法识别章节范围；章节卡片在来源消息标识上增加标题偏移，并打开完整原文摘录。任务结果保持独立可见。成功的文件修改即使在轮次随后失败时仍作为产物；deliverables 所有者提供路径与结果序号。图中的结构边表达轮次归属或已记录的生成关系，从不推断证据支持关系。

来源操作使用现有原始对话分页、过程展开和工具检查器。打开当前文件与查看已记录的修改明确分开。未加载的大纲提问只用于导航，部分历史显示覆盖范围限制。不引入新的 Session 事件、模型请求或持久格式。

[知识工作区提案](../../proposed/architecture/2026-09-05-knowledge-workspace-presentation.zh.md)保留全历史投影、章节导航和结构化摘要设计。本决策约束已加载窗口实现的来源准确性，不代表该提案已完成。[文件链接决策](../feature/2026-07-31-web-workspace-file-links.zh.md)继续负责原生打开与修改词汇表。

## Verification

组合后的 Conversation fixture 覆盖完成、失败、停止、受阻、中断、输出受限、空白、运行中和部分历史材料。它们验证全文、稳定来源序号、实际轮次归属，以及成功和失败的文件修改。minimal Web preset 回放覆盖标明来源的地图、原始回答导航、工具记录检查和折叠工具来源的展开。

## Alternatives considered

**把第一句话称为发现。** 拒绝，因为最新正文可能是过程更新或失败说明。原文摘录不声称完成了独立综合。

**按显示顺序推断工具支持关系。** 拒绝，因为顺序代表时间，不代表归因。未来的语义关系需要明确且有来源依据的生成机制。

**失败后隐藏所有产物。** 拒绝，因为先前成功写入的文件仍有用。任务结果和已记录的文件生成回答不同问题。

## Consequences

- 知识视图可以用于核查来源，而不增加模型延迟或改变 Session 存储。
- 当前文件内容可能与已记录修改不同；用户可以单独检查原始工具记录。
- 较早的详情和产物需要加载历史。全历史覆盖和语义摘要需要提案追踪的专用投影。
