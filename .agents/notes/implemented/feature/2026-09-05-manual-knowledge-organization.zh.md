# Agent Note：手动知识整理

状态：已实施

[English](2026-09-05-manual-knowledge-organization.md) | 中文

## 问题

结构化章节点图重复标题，并将相关主张分散在不同回答中。语义整理需要模型请求，但静默摘要可能遗漏证据，使未经核查的关系显得权威。

## 决策

人工命令在 agent 维护操作所有权下启动一次有界辅助请求。它从完整持久日志读取已完成回答文本，在调用前记录并刷盘精确模型输入，只保存通过验证的结果。主对话保持不变。每个节点和建议关系都引用存在的回答 seq 和精确原文。标识重复、端点无效、引用无据、输入或输出超限、取消及模型未正常结束都会阻止替换上一份成功地图。

全 Session 投影提供分组知识和持久来源目标，不依赖浏览器分页。后续对话消息将已保存地图标记为过期。原始模型 JSON 保留在结果事件中供免密钥重播。客户端提供手动生成、取消、原文引用、原始对话导航，以及切回结构化章节点图的入口。引用匹配只建立来源关系；语义支持和关系标签仍需核查。

[来源决策](../architecture/2026-09-05-knowledge-source-provenance.zh.md)继续规定原始材料的权威性。此生产者实现[工作区提案](../../proposed/architecture/2026-09-05-knowledge-workspace-presentation.zh.md)中的结构化摘要部分；完整章节点投影和研究质量评估仍为独立工作。

## 考虑的替代方案

自动重新生成增加费用，并将阅读变为写操作。复用对话发送路径会污染研究历史。静默截断长研究隐藏遗漏。因此排除这些行为；输入超限时明确失败，并保留现有章节点视图。

## 验证

聚焦模型夹具覆盖无效输出、来源验证、限制、取消和命令卸载。GUI 检查覆盖明确调用、重试、保留旧结果、过期状态和来源导航。交付的 Web profile 重播已记录辅助调用，比对持久 Session，并在浏览器重新加载后恢复整理地图。这些检查建立来源和生命周期行为的证据，不证明研究质量。

## 后果

整理增加明确的模型费用和持久结果，不改写研究历史。大型 Session 需要后续分层生产者；当前请求拒绝隐藏遗漏来源。
